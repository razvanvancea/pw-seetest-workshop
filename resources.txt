== Useful CLI commands ==
All the relevant PW CLI commands are stored in package.json file. You can invoke them using 'npm run' + script name (e.g. npm run test:headed)
CLI command for generating project structure from a plain folder: npm init playwright@latest

CLI command for starting the codegen, open the browser and automatically record tests based on your browser navigation: npx playwright codegen https://practicesoftwaretesting.com
